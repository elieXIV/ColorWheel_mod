Mod Fabric pour Minecraft 1.21.4

Une roue tourne.
Le monde perd ses couleurs.

Toutes les 5 minutes, une roue de loterie s’affiche à l’écran. Quand elle s’arrête, tous les blocs de la couleur tirée disparaissent — et il devient impossible d’en reposer. Couleur après couleur, le monde se vidange, sans jamais revenir en arrière.

Télécharger ColorWheel 1.0.0 Comment ça marche

Comment ça marche

1

La roue tourne

Toutes les 5 minutes par défaut, ou quand tu le décides avec une commande. L’animation dure trois secondes.

2

Une couleur est tirée

La flèche désigne la couleur gagnante, dont le nom s’affiche sous la roue. Une couleur ne peut sortir qu’une seule fois.

3

Elle disparaît

Laine, béton, verre teinté, moquette et blocs naturels de cette couleur sont supprimés, y compris dans les zones que tu explores ensuite.

Treize couleurs, sans nuances

Chaque couleur couvre sa famille de blocs décoratifs (laine, béton, verre teinté, moquette, vitre teintée, terracotta, bougies, boîtes de shulker, lits), plus des blocs naturels associés par leur couleur sur la carte. Poser un bloc d’une couleur déjà supprimée est impossible.

Les blocs essentiels au jeu (coffres, fours, tables de craft, spawners, portails, bedrock…) ne sont jamais supprimés, quelle que soit la couleur tirée.

Commandes

/colorwheel spinLance un tirage tout de suite.
/colorwheel interval <secondes>Change le délai entre deux tirages (ex : 300 = 5 min).
/colorwheel next <couleur>Impose la prochaine couleur, par son nom anglais (RED, BLUE, GREEN…).
/colorwheel radius <blocs>Rayon du nettoyage immédiat autour des joueurs (64 blocs par défaut).
/colorwheel enqueueradius <chunks>Rayon de mise en file au moment du tirage (32 chunks par défaut).
/colorwheel sweepall <true|false>Balaye tous les chunks chargés au lieu d’un rayon (peut ralentir le jeu).
/colorwheel statusAffiche l’état en cours : couleurs tirées, file de nettoyage, prochains tirages.
/colorwheel resetRend toutes les couleurs disponibles. Les blocs déjà supprimés ne reviennent pas.

Installation

1. Fabric

Installe Fabric Loader pour Minecraft 1.21.4.

2. Fabric API

Télécharge Fabric API (par exemple sur Modrinth) pour la même version.

3. Le mod

Place le fichier ColorWheel (.jar) et Fabric API dans le dossier mods, puis lance le profil Fabric.
