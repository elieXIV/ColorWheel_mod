colorwheel_mod the spin minecraft mod
Every 5 minutes, a lottery wheel appears on screen. When it stops, all blocks of the selected color are removed, and it becomes impossible to place any more of that color.
How it works
1
The wheel spins
By default, it spins every 5 minutes, or whenever you trigger it with a command. The animation lasts for three seconds.

2
A color is selected
The arrow points to the winning color, and its name appears below the wheel. Each color can only be selected once.

3
It disappears
Wool, concrete, stained glass, carpet, and natural blocks of that color are removed—even in areas you explore later on.

Thirteen colors, no shades
Each color corresponds to specific blocks: green removes grass and leaves, blue clears away water, and gray makes stone vanish. Placing a block of a color that has already been removed is impossible.

Commands
/colorwheel spin
Triggers a spin immediately.
/colorwheel interval <seconds>
Changes the time interval between spins.
/colorwheel next <color>
Forces the next color to be the one specified (using its English name, e.g., RED, BLUE, GREEN…).
/colorwheel reset
Makes all colors available again. Blocks that have already been removed do not return.
